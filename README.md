## План развития функционала

### Текущая версия

- Возможность проходить тесты, размещённые в директории `Tests`, и получать результат их прохождения.

### Версия 0.1.0

**Планируемые улучшения:**
- добавление теоретической части к тестам;
- реализация функции повторения теории в виде шпаргалки непосредственно внутри теста.

**Исправления:**
- устранена ошибка с проверками ответов при выборе заданий с чекбоксами.

### Версия 0.2.0

Добавление функционала администрирования:
- возможность добавлять, удалять и редактировать тесты;
- возможность добавлять, удалять, редактировать теоретический материал;
- функция связывания теории с соответствующими тестами.

### Версия 0.3.0

- внедрение редактируемого словаря для слов.

### Версия 3.1.0

- добавление функции отображения перевода слова при наведении курсора на него.
