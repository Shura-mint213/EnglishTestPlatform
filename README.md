## Текущая версия 0.2.0

**В данной версии реализованы следующие функциональные возможности:**
- управление тестовыми заданиями (добавление, удаление, редактирование);
- управление теоретическим материалом (добавление, удаление, редактирование);
- связывание теоретических материалов с соответствующими тестовыми заданиями;
- функция повторения теории: отображение краткой шпаргалки с теоретическим материалом непосредственно в интерфейсе теста.

## План развития функционала

### Версия 0.3.0

- улучшения внешнеге вида страниц
- создание разделов чтобы объединять тесты и теорию в один раздел (папку)
  
### Версия 0.4.0

- разные подходы для запоминания

### Версия 0.5.0 

> **ℹ️ Информация**  
> С этой версии начинается этап углублённой специализации в области изучения английского языка. Ранее система позволяла создавать произвольные теоретические материалы и тесты.

- возможность формировать персональный словарь с переводами слов;
- отображение перевода при наведении курсора на слово в тексте (интерактивный словарь в контексте).

Эти улучшения помогут эффективнее осваивать лексику в реальных языковых ситуациях.
